# 出境旅游信息查询 Web应用

这是一个为出境旅游人群提供目的地国家信息的Web应用，包含签证、货币、语言、习俗、路线规划和专业词汇等实用信息。

## 功能特性

### 🌍 国家信息展示
- **首页国家选择界面**：响应式网格布局展示各国信息
- **详细信息页面**：包含6大核心信息模块

### 📋 六大信息模块
1. **签证信息** - 签证类型、申请材料、办理建议
2. **货币汇率** - 当地货币、汇率参考、支付建议
3. **语言交流** - 常用问候语、实用短语
4. **习俗禁忌** - 文化礼仪、注意事项
5. **玩法路线** - 经典旅游路线、景点推荐
6. **高频词汇** - 专业场景词汇、日常用语

### 🔍 交互功能
- **搜索功能**：支持中英文国家名称搜索
- **区域筛选**：按大洲筛选国家
- **模态窗口**：详细信息的标签页展示
- **响应式设计**：适配手机、平板和桌面端

## 技术栈
- HTML5 + CSS3
- Vanilla JavaScript (ES6+)
- 响应式设计
- 模块化架构

## 快速开始

### 方法1：使用Python内置服务器
```bash
cd travel-info-app
python -m http.server 3000
```
然后访问 http://localhost:3000

### 方法2：使用Node.js http-server
```bash
cd travel-info-app
npm install -g http-server
http-server -p 3000
```

### 方法3：直接打开
由于是纯前端应用，也可以直接双击打开 `index.html` 文件
